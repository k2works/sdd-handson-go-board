# GoBoard Bolt 1 計画（ウォーキングスケルトン）

## Bolt ゴール

起動すると空の盤が表示され、座標を 1 つ入力すると犬の駒が置かれた盤が表示されるところまでを、ルール（U1）から画面（U4）まで通して動かす。これで、Go のモジュール構成とテストの流れがこのリポジトリで回るか、絵文字の盤がターミナルでそろうかが分かる。
