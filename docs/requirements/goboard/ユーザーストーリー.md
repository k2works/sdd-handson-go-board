# GoBoard ユーザーストーリー

GoBoard のユーザーストーリーと受入条件です。受入条件は [ルール定義](./ルール定義.md) のルール番号（R1〜R8）にトレースし、Given/When/Then で一意に判定できる形で書きます。ストーリーと受入条件は、プロダクトオーナーと実装者（AI を含む）の契約です。

## アクター

| アクター | 説明 |
| :--- | :--- |
| 犬のプレイヤー | 犬の駒を受け持つプレイヤー。先手（R3・R4） |
| 猫のプレイヤー | 猫の駒を受け持つプレイヤー。後手（R3・R4） |
| プレイヤー | 犬と猫のどちらかを受け持つプレイヤーを区別しないときの呼び方 |

2 人は同じ端末で交互に入力します（[ルール定義](./ルール定義.md)「遊び方」）。

## ストーリー一覧

| ID | ストーリー | Unit | ルール |
| :--- | :--- | :--- | :--- |
| S01 | 対局を始めると空の盤が表示される | U1・U4 | R2 |
| S02 | 空いているマスに駒を置く | U1 | R5 |

Unit の定義は [GoBoard リリース計画](../../development/goboard/release_plan.md) を参照してください。

## S01 対局を始めると空の盤が表示される

**Unit**: U1 盤と着手・U4 CLI 対戦
**ルール**: R2

**として**: プレイヤー
**したい**: 対局を始めたとき、駒が 1 つもない盤を見たい
**なぜなら**: どこに駒を置けるかを確かめてから最初の手を考えたいから

**受入条件**:

- [ ] Given GoBoard を起動していない、When GoBoard を起動する、Then 縦 15 行 × 横 15 列の盤が表示される
- [ ] Given 起動した直後、Then 225 マスすべてが空いているマス（`・`）で表示される
- [ ] Given 起動した直後、Then 盤の上に「GoBoard」という名前が表示される
- [ ] Given 起動した直後、Then 行と列の番号（1〜15）が盤の縁に表示される

**確認ポイント**: 絵文字の表示幅でマス目がずれないか（リスク K1）

---

## S02 空いているマスに駒を置く

**Unit**: U1 盤と着手
**ルール**: R5

**として**: プレイヤー
**したい**: 空いているマスを 1 つ選んで、自分の駒を置きたい
**なぜなら**: 盤の上に自分の駒を増やして並べていくことがゲームの進め方だから

**受入条件**:

- [ ] Given 3 行 4 列が空いている、When 犬のプレイヤーが 3 行 4 列に置く、Then 3 行 4 列が犬の駒になる
- [ ] Given 駒を 1 つ置いた、Then ほかの 224 マスは置く前と同じ状態のままである
- [ ] Given 1 回の手番で 1 つ置いた、Then その手番で置かれた駒は 1 つだけである

---

## S03 駒のあるマスには置けない

**Unit**: U1 盤と着手
**ルール**: R5・R6

**として**: プレイヤー
**したい**: すでに駒があるマスを選んだら置けないと分かりたい
**なぜなら**: 置いた駒は動かず取り除かれないというルールを、ゲームが守ってほしいから

**受入条件**:

- [ ] Given 3 行 4 列に犬の駒がある、When 猫のプレイヤーが 3 行 4 列に置こうとする、Then 置けず、3 行 4 列は犬の駒のままである
- [ ] Given 3 行 4 列に犬の駒がある、When 犬のプレイヤーが 3 行 4 列に置こうとする、Then 置けない
- [ ] Given 置けなかった、Then 手番は置こうとしたプレイヤーのままである（パスにならない）

---

## S04 盤の外には置けない

**Unit**: U1 盤と着手
**ルール**: R2

**として**: プレイヤー
**したい**: 盤の外の位置を選んだら置けないと分かりたい
**なぜなら**: 盤は 15 × 15 に決まっているから

**受入条件**:

- [ ] Given 対局中、When 行または列に 0 を指定して置こうとする、Then 置けない
- [ ] Given 対局中、When 行または列に 16 を指定して置こうとする、Then 置けない
- [ ] Given 対局中、When 1 行 1 列と 15 行 15 列（四隅の 2 つ）に置く、Then どちらも置ける
- [ ] Given 置けなかった、Then 手番は置こうとしたプレイヤーのままである

---

## S05 犬と猫が交互に手番を行う

**Unit**: U2 手番
**ルール**: R4・R5

**として**: プレイヤー
**したい**: 誰の手番かが決まっていて、交互に進んでほしい
**なぜなら**: 公平に 1 手ずつ打ち合いたいから

**受入条件**:

- [ ] Given 対局を始めた直後、Then 手番は犬である
- [ ] Given 犬の手番、When 犬が駒を置く、Then 手番は猫になる
- [ ] Given 猫の手番、When 猫が駒を置く、Then 手番は犬になる
- [ ] Given 犬の手番、Then 置かれる駒は犬であり、猫の駒は置けない
- [ ] Given どちらかの手番、Then 駒を置かずに手番を相手に渡す操作（パス）はない

---

## S06 5 つ以上並べたら勝つ

**Unit**: U3 勝敗判定
**ルール**: R7

**として**: プレイヤー
**したい**: 自分の駒を 5 つ並べたら勝ちになってほしい
**なぜなら**: それがこのゲームの目的だから

**受入条件**:

- [ ] Given 犬が横に 4 つ連続している、When 犬がその延長のマスに置いて横に 5 つ連続する、Then 犬が勝つ
- [ ] Given 犬が縦に 4 つ連続している、When 犬が置いて縦に 5 つ連続する、Then 犬が勝つ
- [ ] Given 犬が右下がりの斜めに 4 つ連続している、When 犬が置いて右下がりに 5 つ連続する、Then 犬が勝つ
- [ ] Given 犬が右上がりの斜めに 4 つ連続している、When 犬が置いて右上がりに 5 つ連続する、Then 犬が勝つ
- [ ] Given 猫が横に 4 つ連続している、When 猫が置いて 5 つ連続する、Then 猫が勝つ
- [ ] Given 犬が 2 つと 3 つに分かれて横に並び、あいだが 1 マス空いている、When 犬がそのあいだに置いて 6 つ連続する、Then 犬が勝つ（5 つ以上）
- [ ] Given 犬が横に 4 つ連続している、When 犬がその並びに接しないマスに置く、Then まだ勝ちではない
- [ ] Given 横に犬 4 つと猫 1 つが連続している、Then 勝ちではない（同じ種類の駒だけを数える）
- [ ] Given 横に犬が 5 つあるが、あいだに空いているマスが 1 つある、Then 勝ちではない（あいだを空けずに連続する必要がある）
- [ ] Given 盤の端に接して犬が 5 つ連続する（例：1 行 1 列〜1 行 5 列）、Then 犬が勝つ

---

## S07 勝負がついたらゲームが終わる

**Unit**: U3 勝敗判定
**ルール**: R7・R8

**として**: プレイヤー
**したい**: 勝ちが決まったら、それ以上駒を置けないようにしてほしい
**なぜなら**: 勝負がついたあとの手で結果が変わってはいけないから

**受入条件**:

- [ ] Given 犬が 5 つ連続させて勝った、When 猫が駒を置こうとする、Then 置けない
- [ ] Given ゲームが終わった、Then 盤の状態は勝ちが決まった時点のまま変わらない
- [ ] Given 最後の 1 マスに置いた駒で 5 つ連続し、同時に盤がすべて埋まった、Then 引き分けではなく、その駒の種類の勝ちになる（R8 は勝ちがない場合の規定のため）

---

## S08 盤が埋まったら引き分けになる

**Unit**: U3 勝敗判定
**ルール**: R8

**として**: プレイヤー
**したい**: どちらも 5 つ並べられずに盤が埋まったら、引き分けで終わってほしい
**なぜなら**: 置ける場所がなくなったらゲームを続けられないから

**受入条件**:

- [ ] Given 空いているマスが 1 つだけで、そこに置いても 5 つ連続しない、When 手番のプレイヤーがそこに置く、Then 引き分けでゲームが終わる
- [ ] Given 空いているマスが 1 つ以上ある、Then 引き分けにはならない

---

## S09 座標を入力して駒を置く

**Unit**: U4 CLI 対戦
**ルール**: R5

**として**: プレイヤー
**したい**: ターミナルで行と列を入力して、駒を置く場所を選びたい
**なぜなら**: 同じ端末で 2 人が交互に遊ぶから

**受入条件**:

- [ ] Given 犬の手番、Then 犬の手番であることと入力の形式が表示される
- [ ] Given 犬の手番、When `8 8` と入力する、Then 8 行 8 列に犬の駒（🐶）が置かれた盤が表示される
- [ ] Given 手番のプレイヤーが置いた、Then 置いたあとの盤と、次の手番のプレイヤーが表示される
- [ ] Given 対局中、When 数字でない入力・数が 2 つでない入力・盤の外の座標・駒のあるマスを入力する、Then 置けない理由が表示され、同じプレイヤーがもう一度入力できる

**AI の仮定（未確認）**:

- A1：座標は「行 列」の順に、1〜15 の数字を半角スペースで区切って入力する
- A2：入力の終わり（EOF、Ctrl+D）や中断（Ctrl+C）で、結果を決めずにプログラムを終える

## S10 対局の結果が表示される

**Unit**: U4 CLI 対戦
**ルール**: R7・R8

**として**: プレイヤー
**したい**: ゲームが終わったら、勝ったのは誰か、引き分けかを知りたい
**なぜなら**: 対局の結果を確かめたいから

**受入条件**:

- [ ] Given 犬が勝った、Then 最後の盤と「犬の勝ち」が表示される
- [ ] Given 猫が勝った、Then 最後の盤と「猫の勝ち」が表示される
- [ ] Given 引き分けになった、Then 最後の盤と「引き分け」が表示される
- [ ] Given 結果を表示した、Then プログラムは入力を待たずに終わる

**AI の仮定（未確認）**:

- A3：続けてもう 1 局遊ぶ機能は、最初のリリースには含めない
