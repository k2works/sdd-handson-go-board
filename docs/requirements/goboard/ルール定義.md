# GoBoard ルール定義

GoBoard は、2 人のプレイヤーが犬と猫の駒を盤に交互に置き、同じ種類の駒を先に 5 つ並べた方が勝つボードゲームです。本書は GoBoard のルールの唯一の正解（Single Source of Truth）であり、実装・テスト・ユーザーストーリーの受入条件はすべて本書のルール番号にトレースします。

## 前提

- 本書に書かれたルールだけを正解とします。似た既存ゲームの一般名称や、その一般的なルール（盤の大きさ、禁じ手、勝ち方など）では、本書の空白を補いません。
- コード・画面・ドキュメントでは、このゲームを「GoBoard」と呼びます。
- 本書にないルールが必要になった場合は、実装者が仮定で決めずにプロダクトオーナーに確認し、本書を改訂してから実装します。

## ルール一覧

「出典」は、そのルールを誰が決めたかを示します。「プロダクトオーナー」はプロダクトオーナーが説明・指定した内容、「案（承認済み）」は AI が提案してプロダクトオーナーが承認した内容です。

| No. | ルール | 出典 |
| :--- | :--- | :--- |
| R1 | 2 人で対戦する | プロダクトオーナー |
| R2 | 盤は縦 15 × 横 15 のマス目で、駒はマスの中に置く | 案（承認済み） |
| R3 | 駒は「犬」と「猫」の 2 種類で、プレイヤーはどちらか一方を受け持つ | プロダクトオーナー |
| R4 | 先手は常に犬で、犬と猫が交互に手番を行う | 案（承認済み） |
| R5 | 1 回の手番で、空いているマスに駒を 1 つだけ置く。パスはできない | 案（承認済み） |
| R6 | 置いた駒は、ゲームが終わるまで動かさず、取り除かない | 案（承認済み） |
| R7 | 同じ種類の駒が縦・横・斜めのどれかの向きに、あいだを空けずに 5 つ以上連続したら、その種類を受け持つプレイヤーが勝ってゲームが終わる | プロダクトオーナー（5 つ並べたら勝ち）＋ 案（承認済み：向き・連続・5 つ以上） |
| R8 | 駒を置いたあとに勝ちを判定する。勝ちがなく、盤がすべて埋まったら引き分けで終わる | 案（承認済み） |

### 判断の理由

| 論点 | 決定 | 理由 |
| :--- | :--- | :--- |
| 6 つ以上並んだ場合（R7） | 勝ちとする | 「5 つ並んだら勝ち」に例外を設けないため。「ちょうど 5 つ」にすると、追加の説明と判定が必要になる |
| 盤の大きさ（R2） | 15 × 15 | 5 つ並べる余地が十分にあり、ターミナルにも無理なく表示できる。実装では定数 1 か所で変更できるようにする |
| 置けない場所（R5） | 駒のあるマスだけ | プロダクトオーナーの説明にない制限は加えない |
| 先手（R4） | 犬 | 特別な根拠はない。先手を決めるルールを単純にするため固定とした |

## 表示

ルールではなく、画面での見せ方の決定です。

| 対象 | 表示 |
| :--- | :--- |
| 犬の駒 | 🐶 |
| 猫の駒 | 🐱 |
| 空いているマス | ・ |

絵文字はターミナルによって表示幅がずれ、盤のマス目がそろわないことがあります。そろわない場合は、漢字の「犬」「猫」で表示する案に切り替えることを検討します。

## 遊び方

最初のリリースは、CLI（ターミナル）で人対人の対戦とし、同じ端末で 2 人が交互に入力します。

## 用語（ユビキタス言語）

| 用語 | コード上の名前 | 意味 |
| :--- | :--- | :--- |
| GoBoard | `GoBoard` | このゲームの名前 |
| 盤 | `Board` | 縦 15 × 横 15 のマス目 |
| マス | `Cell` | 盤の 1 区画。空いているか、駒が 1 つ置かれている |
| 駒 | `Piece` | マスに置くもので、種類は犬か猫 |
| 犬・猫 | `Dog` / `Cat` | 駒の種類。どちらかのプレイヤーが受け持つ |
| 手番 | `Turn` | 駒を 1 つ置く番 |
